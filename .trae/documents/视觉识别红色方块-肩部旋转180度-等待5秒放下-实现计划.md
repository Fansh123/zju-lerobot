## 完整功能流程（修正版）

```
1. 初始化阶段
   ├── 加载机械臂模型 (Pinocchio + Meshcat)
   ├── 初始化摄像头
   └── 机械臂回到初始位置

2. 视觉识别红色方块
   ├── 捕获摄像头帧
   ├── 检测红色方块位置
   └── 返回红色方块在图像中的中心坐标 (cx, cy)

3. 机械臂移动到目标位置（视觉伺服或逆运动学）
   ├── 根据图像坐标计算机器臂目标位置
   ├── 使用逆运动学求解关节角
   └── 平滑移动到目标上方

4. 夹取物块
   ├── 下降至物块位置
   ├── 夹爪闭合（q[5] 从 2.0 降到 0）
   └── 提升一定高度

5. 肩部旋转180度（带着物块）
   ├── 计算目标角度：当前角度 + π
   ├── 使用平滑插值动画
   └── 物块随机械臂一起旋转

6. 等待5秒
   └── time.sleep(5)

7. 放下物块
   ├── 下降至合适位置
   ├── 夹爪打开（q[5] 从 0 升到 2.0）
   └── 提升离开

8. 返回初始状态
   └── 机械臂回到初始位置
```

新建 `vision_control.py` 文件，实现完整流程：

#### 3.1 初始化阶段
- 加载机械臂模型 (Pinocchio)
- 初始化Meshcat可视化
- 初始化摄像头
- 重置机械臂到初始位置

#### 3.2 视觉识别红色方块
- 捕获摄像头帧
- 调用 `detect_red_block()` 检测红色方块
- 如果检测到红色方块，记录位置并继续
- 显示实时画面（可选）

#### 3.3 机械臂移动到目标位置
- 根据红色方块在图像中的位置（cx, cy）
- 估算目标在3D空间中的位置（可使用预设深度或深度摄像头）
- 使用逆运动学求解关节角
- 平滑移动机械臂到目标上方

#### 3.4 夹取物块
- 下降机械臂到物块位置
- 夹爪闭合（q[5] 从 2.0 降低到接近 0）
- 延迟一小段时间确保夹紧
- 提升一定高度

#### 3.5 肩部旋转180度（带着物块）
- 计算目标角度：q[0] + π
- 使用平滑插值动画（如五次多项式或线性插值）
- 动画执行过程中保持夹爪闭合状态
- 确保物块被稳稳携带

#### 3.6 等待5秒
- 保持当前状态
- 使用 `time.sleep(5)`

#### 3.7 放下物块
- 下降机械臂到合适高度
- 夹爪打开（q[5] 从当前值升高到 2.0）
- 延迟一段时间确保物块释放
- 提升离开

#### 3.8 返回初始状态
- 肩部旋转回原位（-180度）
- 机械臂回到初始配置

def main():

def grasp_object(viz, model, duration=1.0):
    """夹取物块：下降 -> 夹爪闭合 -> 提升"""
    q = get_current_joints(model)

    # 下降
    q_target = q.copy()
    q_target[1] -= 0.1  # 肩部下降
    q_target[2] -= 0.1  # 肘部调整
    animate_movement(viz, q, q_target, duration=0.5)

    # 夹爪闭合
    q_grip = get_current_joints(model)
    q_grip[5] = 0.0  # 夹爪闭合
    animate_movement(viz, get_current_joints(model), q_grip, duration=0.5)

    # 提升
    q_up = get_current_joints(model)
    q_up[1] += 0.1
    q_up[2] += 0.1
    animate_movement(viz, get_current_joints(model), q_up, duration=0.5)


def rotate_shoulder_180(viz, model, duration=2.0):
    """肩部平滑旋转180度（带着物块）"""
    q = get_current_joints(model)
    q_start = q.copy()
    q_target = q.copy()
    q_target[0] += np.pi  # 180度

    # 限制关节角度在允许范围内
    q_target[0] = np.clip(q_target[0], model.lowerPositionLimit[0],
                          model.upperPositionLimit[0])

    # 平滑插值动画
    animate_movement(viz, q_start, q_target, duration=duration)


def release_object(viz, model, duration=1.0):
    """放下物块：下降 -> 夹爪打开 -> 提升"""
    q = get_current_joints(model)

    # 下降
    q_target = q.copy()
    q_target[1] -= 0.1
    q_target[2] -= 0.1
    animate_movement(viz, q, q_target, duration=0.5)

    # 夹爪打开
    q_grip = get_current_joints(model)
    q_grip[5] = 2.0  # 夹爪全开
    animate_movement(viz, get_current_joints(model), q_grip, duration=0.5)

    # 提升
    q_up = get_current_joints(model)
    q_up[1] += 0.1
    q_up[2] += 0.1
    animate_movement(viz, get_current_joints(model), q_up, duration=0.5)


def animate_movement(viz, q_start, q_target, duration=1.0, n_steps=20):
    """平滑动画移动机械臂"""
    for i in range(n_steps):
        t = i / n_steps
        # 使用五次多项式插值（更平滑）
        t_smooth = t * t * t * (t * (t * 6 - 15) + 10)  # smoothstep
        q_interp = q_start + (q_target - q_start) * t_smooth
        viz.display(q_interp)
        time.sleep(duration / n_steps)

## 关键改进点（根据用户反馈）

### 夹取步骤
- 在旋转之前必须先夹取物块
- 夹取后物块成为机械臂末端的一部分
- 旋转时物块随末端一起运动

### 带着物块旋转
- 保持夹爪在闭合状态（q[5] ≈ 0）
- 肩部（q[0]）增加 π 弧度
- 其他关节保持当前角度
- 使用平滑动画避免物块脱落（仿真环境）

## 潜在挑战与解决方案

1. **物块在仿真中如何表现**
   - 仿真环境没有物理引擎，物块不会真的"被夹住"
   - 解决方案：物块作为可视化对象，需要手动更新其位置跟随夹爪
   - 或者简化为：只展示动画效果，不实际绑定物块

2. **摄像头兼容性问题**
   - 尝试多个摄像头ID
   - 添加摄像头选择参数

3. **光线条件变化**
   - 红色HSV阈值范围要足够宽
   - 可添加自动白平衡或阈值调整

4. **逆运动学求解**
   - 从2D图像坐标到3D空间需要深度信息
   - 可使用预设深度值或深度摄像头
   - 或者假设物块在固定位置，直接移动到该位置
